清洗完空值只是第一步，接下來要計算感測器數值的平均值，
但如果過濾完之後剛好一筆資料都不剩，直接做除法會讓系統崩潰。

請完成 average_sensor_value(readings) 函式：
先過濾掉 value 為 None 的項目
計算剩餘數值的平均值，四捨五入到小數點後 2 位
若過濾後沒有任何資料，回傳 "Error:無有效資料"

例如輸入 溫度A:20、溫度B:None、溫度C:30
應回傳 25.0（(20+30)/2 四捨五入到小數點後2位）

### 個人化測試
系統會依登入使用者的資料庫 ID 調整測資；請依函式收到的參數計算，不要把範例答案寫死。函式名稱與參數不變，學生不需要自行取得 ID。零值、負數、空資料及錯誤格式等測試仍會保留。
