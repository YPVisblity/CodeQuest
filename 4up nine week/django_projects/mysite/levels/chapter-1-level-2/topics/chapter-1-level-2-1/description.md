請定義一個 basic(height, weight) 函數，利用 if 條件式判斷過輕、正常、過重。

- height 是身高，以「公尺」為單位，例如 1.65 代表 165 公分
- weight 是體重，以「公斤」為單位
- BMI 的計算公式為 BMI = 體重 / 身高²

判斷規則（回傳字串）：
- 若BMI < 18.5 須回傳 "過輕"
- 若18.5 <= BMI < 24 須回傳 "正常"
- 若BMI >= 24 須回傳 "過重"
三種規則皆須寫入程式裡。

例如 basic(1.60, 40) 的 BMI 約為 15.6，應回傳 "過輕"。

### 個人化測試
系統會依登入使用者的資料庫 ID 調整測資；請依函式收到的參數計算，不要把範例答案寫死。函式名稱與參數不變，學生不需要自行取得 ID。零值、負數、空資料及錯誤格式等測試仍會保留。
