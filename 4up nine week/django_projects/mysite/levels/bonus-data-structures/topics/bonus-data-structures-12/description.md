## 進階挑戰（選做，額外徽章 +5 點）

請完成 `shortest_path(graph, start, end)` 函式，利用 BFS 找出從 `start` 到 `end` 的其中一條最短路徑（以節點 list 表示，例如 `["A", "B", "D", "E"]`）。若兩節點不連通，回傳 `None`。

**提示**：在 BFS 過程中，除了記錄 `visited`，也用一個 dict 記錄每個節點是「從哪個節點走過來的」（前驅節點），拜訪到終點後再依前驅節點反推回起點，最後把路徑反轉。

### 個人化測試
系統會依登入使用者的資料庫 ID 調整測資；請依函式收到的參數計算，不要把範例答案寫死。函式名稱與參數不變，學生不需要自行取得 ID。零值、負數、空資料及錯誤格式等測試仍會保留。
