## 進階挑戰
請完成 `infix_to_postfix(expression)` 函式，將中序表達式（如 `"(A+B)*C"`）轉換為後序表達式（如 `"AB+C*"`）。

**提示**：
- 由左至右掃描表達式的每個字元
- 遇到運算元（字母）直接輸出
- 遇到 `(` 直接推入堆疊
- 遇到 `)` 則持續彈出堆疊內容並輸出，直到彈出 `(` 為止
- 遇到運算子時，先彈出堆疊中「優先順序大於等於」目前運算子的符號並輸出，再將目前運算子推入堆疊
- 掃描結束後，將堆疊中剩餘的運算子全部彈出並輸出

### 個人化測試
系統會依登入使用者的資料庫 ID 調整測資；請依函式收到的參數計算，不要把範例答案寫死。函式名稱與參數不變，學生不需要自行取得 ID。零值、負數、空資料及錯誤格式等測試仍會保留。
