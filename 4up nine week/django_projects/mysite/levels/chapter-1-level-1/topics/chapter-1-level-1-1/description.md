小明想去水果攤買蘋果，蘋果一顆 26 元。

請定義 value(x,y) 函式：
x 是單價，y 是購買數量
回傳總價（x*y）
若 x 或 y 為 0 或負數，代表輸入有誤，請回傳 "ERROR"

例如：value(26,6) 應回傳 156

提示：利用 if 判斷式檢查 x 或 y 是否為 0，再用乘法運算子算出總價。
你可以在上方自由測試 value() 的計算結果（例如試著呼叫 value(24,6)），
這只是給你除錯用的，不影響最終評分。

### 個人化測試
系統會依登入使用者的資料庫 ID 調整測資；請依函式收到的參數計算，不要把範例答案寫死。函式名稱與參數不變，學生不需要自行取得 ID。零值、負數、空資料及錯誤格式等測試仍會保留。
