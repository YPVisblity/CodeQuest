請定義一個 matrix_max(matrix) 函數，使用 for 迴圈找出矩陣中最大的數字，並回傳最大值。

輸入說明：
- matrix 是「二維」矩陣，用巢狀 list（list 裡面放 list）表示，每個內層 list 代表一列（row）。
- 矩陣的列數與行數不固定，至少會有一個數字，元素都是整數，也可能全部是負數。

例如：
- matrix_max([[1, 8], [3, 4]]) 應回傳 8
- matrix_max([[-5, -2], [-9, -1]]) 應回傳 -1

提示：最大值的初始值不要設成 0（全部是負數時會出錯），可以先設成矩陣的第一個元素 matrix[0][0]。
