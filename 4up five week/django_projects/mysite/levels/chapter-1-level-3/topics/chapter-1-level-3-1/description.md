請定義一個 matrix_add(A, B) 函數，計算兩個矩陣相加的結果。

輸入說明：
- A 與 B 都是「二維」矩陣，用巢狀 list（list 裡面放 list）表示，每個內層 list 代表一列（row）。
- A 與 B 的大小相同（列數相同、每列的元素個數也相同），元素都是整數。

要求：
- 使用 for 迴圈，將相同位置的元素相加：結果[i][j] = A[i][j] + B[i][j]。
- 回傳一個新的二維 list（不要修改 A 或 B），大小與 A、B 相同。

例如：
A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
matrix_add(A, B) 應回傳 [[6, 8], [10, 12]]

注意：不要使用 numpy，也不要把答案寫死，評測時會用不同的矩陣測試。
