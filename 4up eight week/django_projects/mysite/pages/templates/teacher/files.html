import pybryt

def value(x, y):
    return x * y if x > 0 and y > 0 else "ERROR"

result1 = value(26, 6)
result2 = value(5, 0)

pybryt.Value(result1, name="乘法測試",
             success_message="乘法正確", failure_message="請檢查乘法結果")
pybryt.Value(result2, name="零值測試",
             success_message="零值處理正確", failure_message="請檢查零值處理")

上傳後，後台會執行參考 Notebook，使用 ReferenceImplementation.compile() 及 dump() 自動產生這份作業的 .pkl。不需要自行轉檔，也不要在參考 Notebook 中再放轉檔程式。轉檔失敗時會顯示原因，作業不會發布。

學生 Notebook 需包含測試呼叫並執行程式，不能只有函式定義；不需要另上傳 test.py。

學生的執行過程會由 PyBryt 與這份參考檔比對。教師參考 Notebook 和產生的 .pkl 不提供學生下載。每個檔案上限 10 MB；參考 Notebook 轉檔限時 120 秒。
